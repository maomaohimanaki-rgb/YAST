## Causas e correções

| Sintoma | Causa | Correção |
|---|---|---|
| Nasce como raposa | O initialize (fix do teste 01) rodava também a timeline do emote de transformação | Só constantes de `pre_parallel`/`parallel`, e só atribuições autocontidas |
| Tamanho de formiga | Slider de tamanho (0,2–5) nascia no mínimo; a propriedade atropelava o `?? 1` do modelo | Config "sem valor" (-99999) até o jogador mexer; padrão detectado no modelo; aplicada só quando muda |
| Transformação desfeita | A config reescrevia a variável a cada frame | Idem acima |
| `unknown variable` | Variáveis com `??` ficavam sem init; temporária `t.a` usada entre linhas | Init com o próprio padrão; temporárias só dentro da linha |
| Cabeça/cabelo invertidos | Sinal do pitch | Pitch invertido; `/scriptevent yast:axis pitch\|yaw 1\|-1` |
| Círculos não aparecem | No YSM `pre_parallel` perde para a animação principal; no Bedrock escalas multiplicam | `pre_parallel` vira neutro enquanto o estado principal mexe no mesmo osso/canal |
| Não brilha | `entity_emissive_alpha` depende do alfa da textura | Render controller só dos `ysmGlow*` com `ignore_lighting` |
| Micro-teleporte | `teleport()` não é interpolado pelo cliente | Movimento por velocidade (impulso) + fallback automático; predição 3 ticks |
| Toggle invertido / formulário padrão | — | Ajustes na roda: estado escrito ("Esconder"/"Mostrar", da descrição `A&B` do YSM) |
| Chinês | — | `catalog/traducoes_ptbr.json` (3390 textos) aplicado no build |
| Emote sem nome / faltando | `extraN` fora do mapa do ysm.json | Entram como "Emote N" |
| Peito sem física | ~120 modelos têm o osso e nenhuma animação | Mola de 2ª ordem padrão (os outros 565 já têm a própria) |
